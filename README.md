# ComChat 🗣️💬

**完全無料のP2Pビデオ会議アプリ**

ComChatは、友達や同僚と簡単にビデオ通話ができる、完全無料のWebアプリケーションです。

![ComChat Logo](https://via.placeholder.com/200x100/667eea/ffffff?text=ComChat)

## ✨ 特徴

- **🆓 完全無料** - 時間制限なし、料金なし
- **👥 最大6人** - 同時ビデオ通話対応
- **🚀 インストール不要** - ブラウザだけで動作
- **🔒 プライバシー保護** - P2P通信でサーバーにデータ保存なし
- **📱 レスポンシブ** - PC・スマートフォン両対応

## 🛠️ 主な機能

### 基本機能
- ✅ ビデオ通話（最大6人）
- ✅ 音声通話
- ✅ リアルタイムチャット（メモタブ・新着バッジ付き）
- ✅ 画面共有（プレゼンターモード・全画面表示）
- ✅ カメラ・マイクのオン/オフ
- ✅ 招待システム（ルームID共有・招待リンク・QRコード）
- ✅ 通話経過時間表示（タップで表示/非表示）
- ✅ カメラ・マイクのデバイス選択（通話中に切替可能）
- ✅ タイルのピン留め（ダブルタップで特定の人を拡大表示）
- 📎 ファイル共有（最大200MB）
- 🎨 背景フィルター（ぼかし・背景画像）
- ❤️ リアクション・挙手
- 🎙️ 音声録音
- 🔒 ルームロック
- ↔️ コントロールボタンの並べ替え（左利き対応）

### 今後追加予定
- 📶 接続品質インジケーター

## 🚀 使い方

### 1. ルーム作成
1. 名前を入力
2. 「ルーム作成」ボタンをクリック
3. 生成されたルームIDを友達に共有

### 2. ルーム参加
1. 名前を入力
2. 「ルーム参加」ボタンをクリック
3. 友達から受け取ったルームIDを入力

### 3. 通話開始
- カメラ・マイクの許可を求められたら「許可」をクリック
- 自動的にビデオ通話が開始されます

## 💻 技術仕様

### 使用技術
- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **P2P通信**: PeerJS (WebRTC)
- **スタイリング**: CSS Grid, Flexbox
- **デプロイ**: GitHub Pages対応

### ブラウザ対応
- ✅ Chrome 60+
- ✅ Firefox 55+
- ✅ Safari 12+
- ✅ Edge 80+

### システム要件
- **推奨帯域幅**: 上り 10Mbps以上（6人通話時）
- **推奨CPU**: デュアルコア 2.0GHz以上
- **メモリ**: 4GB以上

## ⚠️ 制限事項

### P2P通信の制約
- **参加者制限**: 6人まで（パフォーマンス理由）
- **ファイアウォール**: 企業ネットワークで接続困難な場合あり
- **安定性**: 参加者の回線品質に依存

### ブラウザ制限
- **HTTPS必須**: カメラ・マイクアクセスにはHTTPS必要
- **ポップアップブロック**: 一部機能でポップアップ許可が必要

## 🐛 トラブルシューティング

### 接続できない場合
1. **ブラウザの更新**: 最新版を使用
2. **HTTPS確認**: HTTPSでアクセスしているか確認
3. **ファイアウォール**: 企業ネットワークの場合は管理者に相談
4. **ブラウザの再起動**: 一度ブラウザを完全に閉じて再起動

### 音声・映像が出ない場合
1. **デバイス確認**: カメラ・マイクが接続されているか確認
2. **権限許可**: ブラウザの権限設定を確認
3. **他のアプリ終了**: 他のビデオ通話アプリを終了
4. **デバイス再起動**: 必要に応じてデバイスを再起動

### パフォーマンスが悪い場合
1. **参加者数確認**: 6人以下に制限
2. **回線速度**: インターネット接続を確認
3. **ブラウザタブ**: 他のタブを閉じる
4. **バックグラウンドアプリ**: 不要なアプリを終了
